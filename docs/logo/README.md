# Conclave 标识

**一只站在钥匙上的猫头鹰。**
GitHub Octocat 那种做法：一枚近黑的圆徽，里面一个白色剪影，细节全靠挖空。
动物选猫头鹰，三层意思都对上：

- **一群猫头鹰在英文里就叫 parliament（议会）** —— 这套东西做的正是「几台机器各自看完、投票、落一个结论」。
- **大眼睛是审阅本身。** 瞳孔略向内下，是在看东西，不是在发呆。
- **夜行。** 它平时就是菜单栏里一个图标，后台一直在跑。

脚下站着一把钥匙：conclave 的词源 *cum clave*，「以钥匙锁闭」（README 第一行那句）。

| 文件 | 用途 |
|---|---|
| `conclave-owl.svg` | 主徽：`#24292F` 圆底 + 白剪影。256×256 |
| `conclave-owl-ink.svg` | 品牌色版：沿用印章方案的墨蓝渐变底，羊皮纸白剪影，只有瞳孔用金 |
| `conclave-owl-mark.svg` | 透明底单色剪影。挖空处是真透明（evenodd），放任何底色上都成立 |
| `conclave-owl-tray-idle.svg` | 菜单栏模板图 · **空闲**：闭眼打盹。22×22 纯黑，只留身形、两道眼缝、一根横杆 |
| `conclave-owl-tray-busy.svg` | 菜单栏模板图 · **评审中**：睁眼。同一身形，两个眼洞 |

**形体上刻意跟猫拉开距离**（第一版在 22px 上读成了猫）：耳羽矮、向外撇（尖端在根部外侧），
头比身子宽，眼睛占掉半张脸。翅膀刻线、瞳孔、钥匙的环和齿在小尺寸上自然消失，剩下的轮廓仍是一只鸟。

几何：身体一笔闭合（`M62 52 … Z`），眼洞 r=24 在 (100,118)/(156,118)，瞳孔 r=9 略偏内下；
钥匙环心 (68,220) r=15，横杆 80→188，齿在 164/176。整组上移 8。

（纯标准库、无依赖，CI 上能重现）：

| 文件 | 说明 |
|---|---|
| `conclave.png` | 1024×1024 App 图标。squircle 底板（近黑渐变）+ 白剪影 + 四层材质；`.icns` 由打包脚本从它缩出来 |
| `conclave.ico` | 256 的 PNG 负载，Windows / Avalonia 窗口图标 |
| `conclave-tray-idle.png` / `conclave-tray-busy.png` | 36px 菜单栏模板图（纯黑 + alpha，带纵向渐隐）。App 按 `NodeState.Reviewing` 换：闲着闭眼，评着睁眼 |
| `conclave-tray-busy-0.png` … `-6.png` | 评审中的呼吸帧，见下。第 0 张跟 `conclave-tray-busy.png` 逐字节相同 |

### 渐变只能做在 alpha 上

菜单栏图标**没有颜色**可言：`setTemplate:YES` 之后 macOS 只拿 alpha 当蒙版，按浅色/深色
菜单栏用标签色自己染，PNG 里的 RGB 全部被丢掉。所以「彩色渐变」在这里不成立 ——
但 alpha 是被尊重的（抗锯齿边缘就是证明），于是能做的是**浓淡**渐变：
菜单栏用它自己的颜色画出深浅。

做法是一道纵向渐隐（`vertical_fade`），从头顶的 1.0 走到脚下的 0.65：

- **上实下虚**，不是反过来。头就是那对眼睛，整个标志的身份在那里，得最实；脚下那根横杆虚下去。
- **0.65 是下限。** 再淡菜单栏上就读成「图标没画完」，而不是「渐变」。
- **起止取字形的真实上下沿**（SVG `y=52` 的耳羽尖 → `y=234` 的横杆底），不是画布边 ——
  否则渐变两端浪费在空白上，中间那截反而看不出变化。

要**真彩**渐变就得放弃模板图：`setTemplate:NO` 之后系统不再管你，深色栏一套颜色、
浅色栏另一套，得自己读 `NSApp.effectiveAppearance`、订 `AppleInterfaceThemeChangedNotification`
重新换图，帧数也翻倍。为一道 20px 高的渐变，不值。

### 评审中会呼吸

评审中那张不是静止的：眼睑一张一合，一秒一次，就是「它正在看」。macOS 没有「会动的
状态栏图标」这回事 —— `NSStatusItem` 只认一张 `NSImage`（animated GIF 塞进去也不会动，
`NSStatusBarButton` 只画静态帧），所以动画就是定时换图，由 `TrayAnimator` 驱动。

几个数都是有来由的：

- **只有 7 张，是半个周期**（全睁 → 最眯）。呼吸是对称的，回程由 `TrayAnimator` 倒着放，
  一轮 `2*(7-1)=12` 拍；存满一圈就是 5 张逐字节重复的 PNG。
- **开度从 1.00 到 0.45**，按余弦取点（两端慢中间快，线性插值看着像机械百叶窗）。
  再眯下去就跟空闲那张闭眼图撞了 —— 那会让人分不清「在评」还是「闲着」。
- **80ms 一拍**，12 拍≈一秒一次呼吸。再快只是白烧电：18pt 上眼睑总共也就动两三个像素。
- **横轴不动、只压纵轴**（`ellipse` 而不是缩小 `circle`）：压下来的是眼睑，不是眼珠变瘦。

没有对应的 SVG：这几帧不是新几何，只是把睁眼那张的 `aperture` 参数调小重渲一遍。
改帧数改 `TRAY_FRAMES`，同时要跟 `App.TrayBusyFrameCount` 对齐：生成的比 App 要的少，
`tray-selftest` 会红（帧解不出来）；多出来的那几张会被悄悄忽略，没人告诉你。

改图案的顺序：**先改 SVG，再把数字搬进脚本**，然后 `python3 scripts/make-icon.py src/Conclave.App/Assets`（约一分钟）。

菜单栏那几张改完**必须看一眼深浅两底**（脚本顶上第 5 条）—— 模板图在图片查看器里是一团黑，
跟它上栏之后的样子没关系。`python3 scripts/preview-tray.py /tmp/tray.png` 做的就是 macOS
那一步染色：放大若干倍，上下两行分别压在浅色栏和深色栏底色上。它是模拟不是截图，
真机上还有壁纸透上来那类因素，最后仍要在真菜单栏上看一眼。
App 图标用 squircle 而不是 SVG 里的圆徽：Dock 里别的图标都是 squircle，一枚圆的会显得矮一截。

## 对比候选：啄木鸟（`conclave-woodpecker-*`）

同一套 Octocat 做法，换成啄木鸟：它专挑木头里的虫，就是 review 在代码里找 bug —— 比猫头鹰更直白。
姿势取最有辨识度的那个：竖着贴在树干上，硬尾巴撑住，长喙伸进树洞，洞里一只刚揪出来的小虫。

| 文件 | 用途 |
|---|---|
| `conclave-woodpecker.svg` | 主徽：`#24292F` 圆底 + 白剪影，靠一圈底色光晕把鸟从树干上分开 |
| `conclave-woodpecker-ink.svg` | 品牌色版：墨蓝渐变底、羊皮纸白剪影，冠用金（真鸟的红冠在这套色里就是这一点金） |
| `conclave-woodpecker-tray.svg` | 22×22 模板图。**只画头**：全身贴树干那版缩到 18px 塌成两根竖条，鸟没了 |

取舍：大图上它的比喻更准、彩蛋更多；小尺寸上它天生吃亏 —— 侧面剪影贴在竖条上，
辨识度只剩冠、喙、尾三根刺，不像猫头鹰那样有一对眼洞撑着。

## 上一版：一方印（已退役，`candidates/seal-*`）

**一方印。** 盖章即定论 —— 这套工具做的事就是「几台机器各自看完代码，最后落一个有签名的结论」，
而「盖章」是中文里对这件事最直接的说法（代码注释里那句「作者给自己盖章」就是这个意思）。
印面上阴刻一个篆刻式的方笃笃 **C**，Conclave 的首字母。

## 文件

| 文件 | 用途 |
|---|---|
| `candidates/seal-conclave.svg` | 应用图标源稿：墨蓝底板 + 印章。512×512，圆角矩形裁切 |
| `candidates/seal-conclave-mark.svg` | 透明底标记，放大 1.3 倍占满画布。README、文档、浅色页面用 |
| `candidates/seal-conclave-tray.svg` | 菜单栏模板图。22×22，纯黑单色，macOS 自己按深浅色反相 |
| `candidates/seal-conclave-wordmark.svg` | 标记 + 字标（`CONCLAVE`，宽字距黑体大写，跟界面顶栏同一套） |

## 为什么长这样

每一条都对应上一轮试出来的六条约束（见 `scripts/make-icon.py` 顶部）：

- **实心体块，不是线条。** 印章本身是一块石头：整个印面是一块实心的羊皮纸白，
  C 是从里面挖掉的。16px 下它仍然是「一块东西」，不会被抗锯齿抹成灰线。
- **材质给设计感，不靠堆元素。** 一共只有四样：底板、印面、两个侧面、一个 C。
  印面左上亮右下暗；C 的刻痕里留一道被光扫到的刻壁（偏亮的一层压在深色下面，
  只在下缘和右端露出两三个像素）。
- **金色只做重点。** 金只出现在石头的两个侧面 —— 光从左上来，右侧面亮金、底面暗金。
  这是「金石」的一小截，整块画面仍然是墨蓝 + 羊皮纸白。
- **先定要表达什么，再画像什么。** 表达的是「定论」。印章是这件事的物件，不是从
  「像什么」倒推出来的轮廓（钥匙孔、双环、白烟都是那条路上的牺牲品）。
- **微微斜着（-7°）。** 盖下去的章从来不是正的；正了就成了对话框里的方框。
  只有菜单栏模板图例外 —— 18px 上一斜就是一圈灰毛边，所以它是正的、也不带侧面。
- **在 16px 与深浅两底上都看过。** 16px：一块斜的浅色方块带一个深色的缺口和一线金边，
  不读成挂锁、证件、头像。浅色底靠 `conclave-mark.svg` 那道 18% 透明度的墨线勾边。

## 几何

印面 300×300，圆角 16，绕画布中心旋转 -7°。侧面向右下挤出 22。
C：外框 176×184，笔画 52，开口向右 ——

```
M-88 -92 H88 V-40 H-36 V40 H88 V92 H-88 Z
```

刻壁那层：同一路径整体缩进 2，向下右各偏 4（`M-86 -86 H90 V-36 H-36 V36 H90 V86 H-86 Z`），
填 `#4A4C7A`，压在 `#1A1C3E` 的 C 下面。

## 字标

`conclave-wordmark.svg` 里的「CONCLAVE」是**轮廓路径，不是文字**。依赖字体的字标在每台机器上
长得都不一样 —— 实测 macOS 自带的 SVG 渲染连 `font-weight` 都不认，粗体出来是细的。

来源：Helvetica Neue Bold · 128px · 字距 18 · 起点 x=300 · 基线 y=196。整行宽 849.4。
要改字就按这组参数用 CoreText 重新导出（`CTFontCreatePathForGlyph` 逐字取路径，Y 轴翻转），
不要手改路径数据。
